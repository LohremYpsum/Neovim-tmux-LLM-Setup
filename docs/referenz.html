Coden mit Neovim, tmux und Claude

Alles, was du für den Alltag im Terminal-Setup brauchst. Grün markierte Abschnitte betreffen tmux, blau markierte Neovim. Das Suchfeld links filtert alle Tabellen.

Das Setup

Ghostty ist das Terminal. Darin läuft tmux, das ein Fenster in mehrere Bereiche (Panes) teilt und Sitzungen offen hält. Im linken Pane läuft Neovim als Editor, im rechten Claude Code als KI-Agent.

 Ghostty
Neovim65 %
Code lesen & bearbeiten
Claude Code35 %
Aufgaben geben
[mein-projekt] 1:code · tmux-Statusleiste mit Tabs

Ändert Claude eine Datei, lädt Neovim sie automatisch neu, sobald du ins Neovim-Pane zurückwechselst.

Projekt öffnen terminal

Der Befehl dev startet das Layout. Gib den Projektordner an:

dev ~/Projekte/mein-projekt

Bist du schon im Projektordner, reicht dev allein:

cd ~/Projekte/mein-projekt
dev
EingabeWirkung
dev pfadSession für den Ordner anlegen und öffnen. Der Session-Name ist der Ordnername.
devDasselbe für das aktuelle Verzeichnis
dev erneutLäuft die Session schon, landest du wieder darin. Es wird keine neue angelegt.
Ctrl+bdannaSchon in tmux: Layout als neuen Tab im aktuellen Verzeichnis anlegen
Ctrl+bdannsListe aller Sessions, um zwischen Projekten zu wechseln

Sessions verlassen & beenden tmux

EingabeWirkung
Ctrl+bdanndSession verlassen (detach). Neovim und Claude laufen weiter, dev holt dich zurück.
tmux lsAlle laufenden Sessions anzeigen
tmux kill-session -t nameEine Session beenden
Ctrl+bdann: kill-sessionAktuelle Session aus ihr heraus beenden
tmux kill-serverAlle Sessions beenden
Achtung: Beim Beenden einer Session werden Neovim und Claude hart geschlossen und ungespeicherte Änderungen gehen verloren. Sicherer: in Neovim :wqa, in Claude /exit. Sind alle Panes zu, schließt sich die Session von selbst.

Modi & Einfügen neovim

Neovim hat Modi. Im Normal-Modus lösen Tasten Befehle aus, im Einfüge-Modus tippst du Text. Esc bringt dich immer zurück in den Normal-Modus. Im Einfüge-Modus steht unten links INSERT.

Aam Ende der Zeile

Für den Anfang reichen i zum Schreiben und Esc zum Aufhören.

EingabeWirkung

Löschen, Kopieren, Einfügen neovim

Vim-Befehle sind wie Sätze aufgebaut: Aktion + Bewegung. d heißt löschen, w heißt Wort, also löscht dw ein Wort. d$ löscht bis zum Zeilenende, y} kopiert bis zum Absatzende.

TasteWirkung

dd / 3ddZeile / 3 Zeilen löschen
DVom Cursor bis Zeilenende löschen
yy / 3yyZeile / 3 Zeilen kopieren (yank)
ywBis zum nächsten Wort kopieren
pEinfügen nach dem Cursor bzw. unter der Zeile
PEinfügen vor dem Cursor bzw. über der Zeile
uRückgängig
Ctrl+rWiederherstellen

Mit Markieren

  1. v startet die Markierung ab dem Cursor, V markiert ganze Zeilen. Mit der Maus ziehen geht auch.
  2. Mit Bewegungstasten die Markierung erweitern.
  3. y kopiert, d löscht, p ersetzt die Markierung.
Zwischenablage: Neovim nutzt die macOS-Zwischenablage. Mit y Kopiertes fügst du mit Cmd+V überall ein, etwa im Claude-Pane. Gelöschter Text landet auch dort, Ausschneiden ist also löschen und dann p.

Wo die Konfiguration liegt

Alle Dateien liegen im Git-Repo ~/dotfiles. An den gewohnten Orten stehen nur Symlinks darauf, Änderungen landen also direkt im Repo. Auf einem neuen Rechner richtet ~/dotfiles/install.sh alles ein.
